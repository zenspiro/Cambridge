# User guides

Guides for students, reviewers and admins go here, one file per audience, updated whenever what they see changes. - `admin.md`: signing in, lockouts, recent activity, library (subjects, status, checklist, search, adding files), upload, approved sources, start pages, download agent, settings.
- `agent-setup.md`: the two secrets the download agent needs, step by step.
- `topic-tree-setup.md`: the subject brain's topic tree: the two AI keys, drafting a tree, what Ready means.
