Codes are read from brackets ("(0478)", never a year) or when they are library codes; a bare number like "1524" is never a code. A run reads only the folders for its own subject: a folder whose label (or Drive name, if unlabelled) names another code is skipped without a call to Google (`driveSkipped` in the report). - Needs your eye (owner request 4 Nov 2026): Drive files nobody could place (rules or AI) go to `report.review` as items `{where, why, driveId, siteId, suggest?, by}` (up to 200; old reports hold strings, shown only).
